# История изменений репозитория SUNKORA ROLEPLAY

Это журнал изменений **репозитория GitHub**, а не заявка о готовности игрового мода. Названия ранних архивов `v0.x` не являются тегами релиза работающего сервера.

## Невыпущено — защита приватных тем форума

- Закрыты переносы тем между разделами с разными режимами доступа и смена режима раздела с уже созданными темами.
- При публикации темы и ответе перепроверяется актуальная блокировка участника и режим раздела внутри транзакции записи.
- При регистрации повторно проверяется разрешение регистрации и техническое обслуживание внутри блокировки базы.
- Добавлены регрессионные тесты приватных тем, ролей и настроек доступа.

## Невыпущено — исправление регистрации и входа

- Сравнение логинов и ников на сайте теперь учитывает регистр кириллических букв (включая Ё), даже когда не установлен `mbstring`.
- Проверка уникальности имени и почты выполняется в одной блокировке записи с повторной проверкой разрешения регистрации, чтобы настройка администратора не обходилась при гонке запросов.
- Добавлены тесты поиска аккаунта и регистрации с кириллическими именами.

## Невыпущено — улучшение надёжности веб-части

- Исправлена проверка размера HTTP POST в сайте: сравниваются байты, а не количество цифр в `Content-Length`.
- Сохранение данных сайта переведено на запись во временный файл с атомарной заменой и отдельным файлом блокировки.
- Добавлены регрессионные тесты корректного лимита, совместимости JSON-хранилища и сохранения данных при ошибке.

## Обслуживание структуры репозитория

- Приведены в порядок главная страница проекта, правила Git и форматы файлов.
- Документированы раздельное размещение трёх PHP-приложений и их реальные ограничения.
- Добавлена автоматическая проверка целостности путей и статических ресурсов.

## 17 ноября 2026 — защита веб-приложений

- Установочные ключи вынесены из текущих PHP-файлов в переменные окружения.
- Добавлены правила запрета прямого HTTP-доступа к хранилищам на Apache.
- Для Wiki предусмотрено хранение базы вне публичного web root.
- Добавлены проверки PHP в GitHub Actions.

## Не завершено

- Игровых исходников Pawn в репозитории нет.
- Игровой сервер, MySQL, CEF и клиент не прошли интеграционные испытания.
- Публичный релиз SUNKORA ROLEPLAY **не объявлен**.
