# История изменений репозитория SUNKORA ROLEPLAY

Это журнал изменений **репозитория GitHub**, а не заявка о готовности игрового мода. Названия ранних архивов `v0.x` не являются тегами релиза работающего сервера.

## Невыпущено — обслуживание структуры репозитория

- Приведены в порядок главная страница проекта, правила Git и форматы файлов.
- Документированы раздельное размещение трёх PHP-приложений и их реальные ограничения.
- Добавлена автоматическая проверка целостности путей и статических ресурсов.

## 17 ноября 2026 — защита веб-приложений

- Установочные ключи вынесены из текущих PHP-файлов в переменные окружения.
- Добавлены правила запрета прямого HTTP-доступа к хранилищам на Apache.
- Для Wiki предусмотрено хранение базы вне публичного web root.
- Добавлены проверки PHP в GitHub Actions.

## Не завершено

- Игровых исходников Pawn в репозитории нет.
- Игровой сервер, MySQL, CEF и клиент не прошли интеграционные испытания.
- Публичный релиз SUNKORA ROLEPLAY **не объявлен**.
