# План разработки SUNKORA ROLEPLAY

## Текущий статус

| Направление | Состояние |
| --- | --- |
| Сайт | Исходники есть, проверка боевого размещения отсутствует |
| Форум | Исходники есть, проверка боевого размещения отсутствует |
| Wiki | Исходники есть, проверка боевого размещения отсутствует |
| Графика | Исходные фирменные материалы присутствуют |
| Сервер SA-MP/open.mp | Минимальный оригинальный Pawn-режим (не большой RP-мод) |
| `sunkora.amx` | Реально собран PawnCC в GitHub Actions, не запускался с игроками |
| MySQL, CEF, лаунчер | Не проверены вместе с игровым сервером |

Зелёный статус PHP CI означает, что пройдены **статические проверки**, а не что вся игра или все веб-приложения протестированы в продакшене. Pawn Workflow компилирует только новую экспериментальную основу; это не тест полноценного игрового сервера.
