# Развёртывание SUNKORA ROLEPLAY

Этот документ относится к **сайту, форуму и Wiki на PHP**. Игровой сервер Pawn в GitHub пока отсутствует.

## Требования

- PHP **8.1+** и веб-сервер с HTTPS.
- Для `.htaccess` — **Apache 2.4+** и включённый `AllowOverride`.
- PHP должен иметь право записи только в нужные каталоги состояния.
- Сайт, форум и Wiki лучше размещать на разных поддоменах или в раздельных document root.

| Приложение | Корень | Каталог с данными | Установочная страница |
| --- | --- | --- | --- |
| Сайт | `Сайт/` | `Сайт/data/` | `?page=setup` |
| Форум | `Форум/` | `Форум/storage/` | `?p=setup` |
| Wiki | `Вики/` | `Вики/storage/` | `?page=setup` |

## Подготовка

1. Выгрузите выбранные каталоги без `.git/`, логов, тестовых данных и локальных секретов.
2. Создайте **три разных** случайных ключа (например, `openssl rand -hex 32` три раза).
3. Установите `SUNKORA_SITE_INSTALL_KEY`, `SUNKORA_FORUM_INSTALL_KEY` и `SUNKORA_WIKI_INSTALL_KEY` в **окружении PHP**, а не в репозитории.
4. Дайте PHP запись в нужный каталог данных, но не всему сайту целиком.
5. Откройте установочную страницу, укажите соответствующий ключ, создайте администратора.
6. Проверьте вход, выход, резервные копии, сохранение данных, HTTPS и отказ прямого доступа к приватным файлам.

Ключи, опубликованные в старой истории GitHub, **не использовать**: заменить все три.

## Безопасный веб-сервер

Для Apache в каталогах `app/`, `config/`, `data/` или `storage/` уже есть правила `.htaccess`. Их действие нужно проверить на вашем хостинге.

Для Nginx (при расположении приложения в корне виртуального хоста) необходим аналогичный запрет. Пример фрагмента для `server { ... }`:

```nginx
location ~ ^/(?:app|config|data|storage)(?:/|$) { return 404; }
location ~ ^/assets/uploads/.*\.(?:php[0-9]?|phtml|phar)$ { return 404; }
```

При размещении приложений **в подпапках** скорректируйте пути под вашу конфигурацию. Не отключайте запреты при настройке ЧПУ. Проверяйте фактический HTTP-ответ на запросы к `/storage/wiki.json`, `/data/store.php` и каталогу конфигурации: должен быть **403 или 404**.

Для Wiki предпочтительно хранить данные вне web root. До запуска создайте каталог, доступный PHP на запись, например `/var/lib/sunkora/wiki`, и задайте:

```text
SUNKORA_WIKI_STORAGE_DIR=/var/lib/sunkora/wiki
```

Если Wiki **уже установлена**, сначала безопасно перенесите все файлы `Вики/storage/` (включая `wiki.json` и `login-limits.json`) во внешний каталог, а затем поменяйте переменную окружения; иначе приложение может начать новую установку.

## После установки

- Не храните на веб-сервере открытые резервные копии или SQL-дампы.
- Проверьте доступность оригинальных изображений SUNKORA и кодировку UTF-8.
- Сделайте резервную копию, затем проверьте восстановление в тестовой среде.
- Не подключайте настоящие платежи до проверки интеграции.
- Учётные записи сайта, форума и Wiki **отдельные** — единый вход ещё не реализован.
- Игровая экономика и мониторинг требуют реального SA-MP/open.mp-сервера.
