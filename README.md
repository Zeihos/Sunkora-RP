# SUNKORA ROLEPLAY

[![PHP checks](https://github.com/Zeihos/Sunkora-RP/actions/workflows/php-checks.yml/badge.svg)](https://github.com/Zeihos/Sunkora-RP/actions/workflows/php-checks.yml)

**SUNKORA ROLEPLAY** — RP-проект в экосистеме SA-MP / open.mp. Репозиторий объединяет веб-компоненты и фирменное оформление проекта.

> **Состояние:** сайт, форум и Wiki представлены исходниками PHP. Игровой сервер **пока не загружен в GitHub**, не скомпилирован и не протестирован в этом репозитории. Успешный статус workflow «Pawn Compile» без исходников не является результатом компиляции.

## Запуск веб-компонентов

Нужны PHP **8.1+** и настроенный веб-сервер. Для Apache используйте 2.4+ с разрешёнными правилами `.htaccess`; для Nginx обязательна отдельная защита служебных каталогов. Не публикуйте папки с данными напрямую.

1. Разместите `Сайт/`, `Форум/` и `Вики/` как отдельные приложения (или отдельные корни поддоменов).
2. На сервере создайте **три разные** переменные окружения: `SUNKORA_SITE_INSTALL_KEY`, `SUNKORA_FORUM_INSTALL_KEY` и `SUNKORA_WIKI_INSTALL_KEY`. Для каждого ключа используйте новый результат `openssl rand -hex 32`.
3. Обеспечьте право PHP на запись в соответствующие каталоги данных.
4. Откройте установку: сайт — `?page=setup`, форум — `?p=setup`, Wiki — `?page=setup`.
5. Проверьте HTTPS, запрет доступа к приватным файлам, резервное копирование и вход администратора перед открытием для игроков.

Подробности и конфигурация безопасности: **[Развёртывание](docs/DEPLOYMENT.md)** и **[SECURITY.md](SECURITY.md)**.

**Важно:** прежние ключи установки были опубликованы в истории Git. Перед любым развёртыванием замените их новыми; изменение текущего кода не стирает историю.

## Разработка и проверки

- `.github/workflows/php-checks.yml` — проверка синтаксиса PHP, установочных ключей, приватного хранилища Wiki и структуры репозитория.
- `.github/workflows/pawn-build.yml` — обнаружение игровых исходников и компиляция *только после* появления полного исходного комплекта в `server/`. Пока файлов нет, компиляция пропускается.
- `tools/` — локальные тесты, запускаемые из GitHub Actions.
- [План разработки](docs/ROADMAP.md) · [История изменений в репозитории](CHANGELOG.md).

Для локальной проверки веб-части:

```bash
php tools/verify-install-keys.php
php tools/test-storage-security.php
php tools/verify-repository.php
```

Не загружайте в публичный Git секреты, пользовательские базы, резервные копии, непроверенные бинарные плагины и сторонние исходники без права на распространение.
