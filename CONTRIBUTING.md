# Как участвовать в разработке SUNKORA ROLEPLAY

Спасибо за интерес к проекту! Репозиторий публичный, а замечания и предложения помогают улучшать сайт, форум и Wiki.

## Прежде чем создать Issue

- Посмотрите [существующие обращения](https://github.com/Zeihos/Sunkora-RP/issues), чтобы не дублировать тему.
- Выберите подходящий русскоязычный шаблон: **ошибка** или **предложение**.
- Укажите компонент (`Сайт`, `Форум`, `Вики`, `Оформление` или будущий сервер).
- Для ошибки добавьте воспроизводимые шаги и ожидаемый результат; по возможности — скриншот без личных данных.
- Никогда не прикладывайте ключи, пароли, содержимое приватных баз и персональные данные.

## Предложение изменений через Pull Request

1. Создайте отдельную ветку от актуальной `main` и делайте небольшие, связанные изменения.
2. **Не переименовывайте** существующие папки `Сайт/`, `Форум/` и `Вики/` без обсуждения: они используются при размещении.
3. При изменении PHP выполняйте проверки:

   ```bash
   php tools/verify-install-keys.php
   php tools/test-storage-security.php
   php tools/verify-repository.php
   ```

4. В Pull Request объясните, что изменилось, как проверялось и нужны ли изменения в настройках хостинга.
5. Если меняете внешний вид — добавьте скриншоты **до и после**.

## Стиль и безопасность

- Предпочтителен русский язык в документации, Issues и обсуждении изменений.
- Не добавляйте рабочие данные пользователей, временные файлы, `.env` и исполняемые файлы неизвестного происхождения.
- Сохраняйте существующий дизайн SUNKORA и совместимость ссылок между компонентами.
- Исходники игрового мода и клиентские ресурсы можно публиковать только при наличии соответствующих прав.
- Репозиторий пока **без опубликованной лицензии**. Это не означает разрешения на использование файлов в сторонних продуктах.

Если обнаружили уязвимость, не выкладывайте способы её эксплуатации публично — см. [SECURITY.md](./SECURITY.md).
