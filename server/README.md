# SUNKORA RP — сервер

Здесь будут храниться **разрешённые к публикации** исходники Pawn.
Сейчас игрового мода в этом репозитории нет, и выпуск релиза не подтверждён.

## Ожидаемая структура

- `gamemodes/sunkora.pwn`
- `filterscripts/other.pwn`
- `pawno/include/`
- `BUILD-LINUX.sh`
- `BD/schema.sql` и миграции, без аккаунтов игроков
- чистые конфигурации без секретов

После добавления исходников запустите **Pawn Compile** в GitHub Actions.
При успешной компиляции проверьте полученные `.amx` на отдельном сервере.
Не загружайте сторонние бинарные плагины и клиентские ресурсы без проверки
их безопасности и права на распространение.
